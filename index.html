About Oste Repository

A collection of custom Kodi add-ons, built to make your media experience better.

No affiliation with the content distributors.


TubeLink

Install via Kodi repository

  • Add the following URL as a file source in Kodi: https://raw.githubusercontent.com/Liutprando08/oste_repository/main/zips/ and name it "Oste Repo"
  • Open Kodi and go to Add-ons → Install from zip file → Oste Repo
  • Select repository.oste-2.5.3.zip and click it
  • Now you can install any add-on from the Oste Repository

Install directly via zip

  • Download the zip file: click here
  • Open Kodi and go to Add-ons → Install from zip file
  • Select the file just downloaded and install it
  • Now you can install any add-on from the Oste Repository
