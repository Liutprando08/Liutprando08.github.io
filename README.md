# Oste Repository - GitHub Pages

Official website for the Oste Kodi add-on repository.

## Add-ons

- **repository.oste** - Repository installer for Kodi
- **plugin.video.tubelink** - YouTube playback via yt-dlp, no API key needed
- **plugin.video.onepace** - One Pace fan-edited One Piece anime
- **plugin.audio.mp3streams-remastered** - Music streaming and downloading

## Installation

Add this source URL in Kodi:

```
https://raw.githubusercontent.com/Liutprando08/oste_repository/main/zips/
```

Then install from zip file and select `repository.oste`.
